How each refresh works

  1. Every {{ interval }} minute{{ interval|pluralize }} the scheduler fetches the live market snapshot — prices, caps and volumes for all coins in a single API call.
  2. Price histories are hourly, so they only gain a bar once an hour; downloads younger than {{ history_cache }} minutes are reused. The full 100-coin history download happens roughly hourly.
  3. The analysis reruns, a new snapshot is stored, and open pages reload onto it automatically, keeping the coin and filters you had selected.
  4. If a refresh overruns its slot, the next tick is skipped rather than stacked.
